# 现有功能插件迁移清单

本清单覆盖 Feature Map 中每个已登记条目，单列迁移口径。产品功能的“已完成”不代表插件迁移完成；manifest 仅用于定位可能的 owning 包，不是完成证据。待核实不等于待重新实现，优先复用并核对已存在的业务和生命周期证据。

只迁移已经实现的业务。未实现的 connector、Evals 与自动 RSI 生成／晋级／部署不在本轮新增范围；固定 Loop、凭据、权威事实、授权、事务、隐私、冻结、恢复及独立控制保留 Host／Guardian。共享控件和纯传输 driver 不按每个函数拆插件。

## 完成判定

每个现有业务须闭合四项证据：实际入口调用 owning 实现；原数据、Run／Child 和已发布引用适用的兼容；独立换版、精确回退、停用／冷恢复与适用的审批／Forget／unknown 不重放；替代实现、死字段和过渡代码当次清理。兼容保留须注明具体消费者、原因及删除条件。没有证据的项目不标为完成，也不据插件数量换算进度百分比。
