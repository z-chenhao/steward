# Developer Memory：只读记忆投影

[功能与需求](../features/memory.md) · [测试方案](../test-plans/memory.md) · [主索引](../feature-map.md)

## 需求、使用者与边界

本机所有者需要浏览真实记忆及来源；Web 是现有所有者读取权的消费者。原 Database 通用元数据浏览器及其专用三库连接池已移除，领域存储、Agent Tool、维护队列、召回与加密格式不变。沿用既有私有 schema；本次插件迁移不增加持久表或公开持久化模型。

## 读取机制

[Memory 私有投影](../../internal/memory/inspection.go) 定义有界查询、记忆项、来源与维护回执；[Memory Store 读取](../../internal/memory/sqlite/inspection.go) 使用现有连接池和 Vault。[Runs 所有者读取](../../internal/agent/sqlite/memory_inspection.go) 从配置派生当前用户／Agent 与隐私 epoch、floor，调用存储并校验每条来源。App 只负责组合，Web 不能指定作用域。

Store 在只读事务中读取作用域内、未删除、隐私 floor 之后的记录及替代关系，关闭事务后访问 SecretStore。只解密当前有效正文；被替代正文始终不可见。reserved sealed: 表示不能降级成普通文本。搜索采用 Unicode 文本的小写字面包含匹配；当前本机语料在内存中扫描，5 秒读取预算内失败则整体失败，不返回截断的成功搜索。此实现适合当前个人记忆规模，大规模索引优化未稳定为新协议。

分页按创建时间／ID 降序，游标绑定所有者、隐私 floor 和搜索／过滤／视图条件；游标只表示位置，不提供授权。输出前重读元数据指纹，检查成员、密文表示、来源和替代关系是否改变，再重新检查所有者及隐私 epoch。遗忘、纠正、加密保护或切换配置发生在读取期间，不能返回旧结果。明文只存在于请求内存和所有者响应，不写入日志、工具结果、事件或持久搜索索引。

## 来源和维护记录

Conversation／Task 引用复用既有证据可见性校验；来源正文复用有界 evidence 读取，来源按每页最多 20 条显式续读，且请求的 source 必须属于该记忆当前可见来源页。feedback 仅映射到当前 Agent 的确切 builtin__memory_manage ToolInvocation，或已保存的本机控制请求，不推断关联。替代链接仅指向当前查询边界内仍可见的未删除元数据。

维护页只投影当前 Agent 的 remember／forget／Dream 回执，不解密 payload；applied／rejected／pending 来自已保存的时间字段，错误保持维护管线的脱敏代码。记录分页有界，来源 Run 另受隐私 floor 约束。

## 页面与共享组件

列表与 Traces 共用 compact 密度、过滤栏、表格和响应式布局；详情直接消费共享 [sheet](../../web/src/components/ui/sheet.ts)、[split-view](../../web/src/components/ui/split-view.ts) 和 [resize-handle](../../web/src/components/ui/resize-handle.ts)。Memory 页面只拥有筛选与选择状态，不复制控件皮肤。颜色沿用已有类型／状态语义；层级与状态始终有文字。浏览器只持久化宽度比例，不保存记忆正文、来源正文或搜索结果。

列表链接渐进增强为非模态半屏详情，支持来源选择、前后条目、展开、独立页面、返回与焦点恢复。原生导航和无脚本表单保持有效。旧 Database 页面与 API 直接移除，不保留泛型存储检查接口；新接口是私有所有者读投影，尚未作为第三方稳定契约。

## 取舍

复用领域读取和现有 Vault，避免另建解密或维护路径。首次实现选择清晰的全量候选扫描与输出前复查，避免引入落盘明文索引。没有通用 SQL、任意表投影、正文编辑、分类推断、召回统计或数据写入入口。后续大规模检索或可编辑管理需要独立证据与生命周期设计。

## 四层投影

查询增加固定 `layer=transcripts|notes|representations|injected`，默认为 notes。Transcripts 读取所有者可见原始 Conversation，按时间/身份排序分页，并提供明确关联的 Trace；其他层复用 Store 的有界检视与输出前复查。层级、筛选与隐私 floor 都参与游标绑定。文档标题、正文、关系与修订来自保存的领域数据，不能通过浏览器指定表、SQL、文件路径或其他用户。

四层导航、列表和详情复用 Traces 的共享 compact 规格、sheet、split-view 与 resize-handle。文档链接通过同一详情侧栏导航；原始来源仍逐跳验证，退役/被替代正文不可见。维护回执保留独立视图，GET 不触发 Dreaming、模型调用、embedding 或记忆写入。


维护记录的指标来自宿主只读一致性快照；字段包含模型与已知用量、分币种参考费用及未知项、文档修改／退役／无变化、后续工具读取与注入。曝光不是有用性评分，JSON 投影不扩展数据库查询权限。Owner inspection 的 scope 与执行端统一来自持久的 Host 所有者绑定。


维护列表包括 remember／forget 和 Dream 事件，使用同一所有者检视与分页，维护详情只读。Transcripts 使用 state 51 的原始时间投影索引；常规页／详情不再加载全部对话。字段仍来自所属领域，未知用量／费用保留未知，参考费用不作为账单。

形成方式条件必须在解密文档元数据、取得最终 origin 后判断，不能提前按原始来源类型推断。退役／被替代记录仅恢复 origin，不恢复标题、正文和链接；元数据不可用时形成方式查询整体失败。页面的记录浏览与运行审计边界见[功能说明](../features/memory.md#审计覆盖边界)，不将当前 L4 文档冒充某次请求的冻结快照。

## Memory Inspector 插件迁移

### 需求与所有权

现有所有者 Memory 列表、详情、来源和维护工作台需要整套独立换版，保留原 API、正文、来源与已发布引用。`steward.memory-inspector` 持有导航、默认状态、标签、页面、样式、本地化和浏览器交互决策；实际消费者是所有者页面与其冻结资源路由。契约 `steward.memory-inspector-presentation/1` 为私有实验，不扩展公共 SDK，不直接导出内部 InspectionPage。

| 插件政策／实现 | Host 不变机制 |
| --- | --- |
| 查询导航、展示标签和默认状态 | 原查询协议、范围、权限和权威事实读取 |
| 同包 HTML、CSS、中英文 copy | 模板／样式接纳、记录与链接身份校验 |
| 筛选栏、点击、相邻项、恢复与历史动作决策 | DOM、同源导航、请求取消、过期回复拒绝 |
| 四项资源的独立版本 | 冻结图、资源哈希、停用边界和隐私复查 |

Host 在原页面／快照读取后调用隔离 producer，再执行原有快照、隐私和所有者复查；正常、Transcripts 和维护分支均不能绕过最终检查。Go producer 只接当前只读路由的导航值，不接页面正文、来源文本、SQL 或凭据。原 Memory API 保持权威读取协议，展示插件停用不会改写事实或 API。

### 私有资源与接纳

一次响应持有导航／标签和 `views/memory.html`、`views/memory.css`、`views/copy.json`、`views/memory-worker.js`。Host 按同一冻结包的声明和哈希接纳资源，按请求绑定模板函数，不逐字段重新派发。CSS／程序路由只读资源，无 Memory 查询／文档参数，不为加载资源再次读取正文。

HTML 只使用 Memory 的窄类型视图、原格式化函数和共享原语；AST／输出有界，不允许递归模板、跨页面数据、主动脚本／事件、外部 URL、隐藏权威正文或替换记录身份。整页缓冲后发布，失败不输出部分正文。CSS 仅接受原 Memory 选择器和有界被动属性；不允许网络、隐藏、主动内容或跨功能控制。原 Apps／Memory 两个实际消费者共享被动样式校验机制，各自保留自己的选择器和属性边界。

中英文 copy 同图冻结；托管片段和客户端不回退全局字典，未知诊断文字保留原文。Host 生成的惰性 JSON 配置只有 revision／copy，使用安全 JSON 转义。Shared shell、日期、标识符和帮助原语仍由其原拥有者提供。

### 浏览器边界与生命周期

`memory-browser.ts` 经受保护资源路由连接 opaque iframe 和 Worker。复用 Apps 已有的可信 relay，功能程序、频道和结果校验各自独立；不开放通用 DOM／效果总线。Worker 只接布尔值、索引和本页历史深度，无正文、记录 ID、URL、DOM、凭据、网络或存储能力。Host 将结果限制在当前实际节点／链接和本页历史范围，并拒绝过期选择和异常回复。

程序／样式／copy 必须使用同一冻结图。程序失败保留原版本服务端链接，不执行旧客户端。pagehide 销毁 Worker／侧栏；persisted pageshow 先连接原冻结图，再恢复原选择，不重选默认版本。未知序号、失败回复、超时或超大回复终止通道。浏览器恢复测试实际派发生命周期事件，不宣称强制取得浏览器 BFCache 接纳。

### 默认分发与兼容清理

标准33包构建封存上述四项资源，完整分发缺包则拒绝，不静默使用原生实现。首次安装复用 EnsureDefault 和独立 Owner 原始期望；已有选择、停用和停止优先，不随新分发自动升级或修复。Owner 固定原导航／页面／样式／copy 和审阅后的 Worker 字节；Worker 语义另由原客户端执行捕获案例对照，字节相等不替代行为验证。

从未启用本服务的原32／更早组合，以及显式直接无 bundle 嵌入页面，仍是具名历史消费者；启用后的停用或缺包不恢复原生。其模板、样式、客户端与函数分别限于 `legacy-ui/memory-v1/`、`web/src/legacy/memory-v1.ts` 和 `memory_legacy_v1.go`；当前托管页不调用这些历史实现。消费者退役后删除对应资源；没有两个当前默认实现。共享 Developer 导航独立于历史 Memory 模板。

### 取舍

保留权限、事实、事务、版本、隐私复查和接纳校验，是现有真实消费者所需的机制；业务标签、样式、布局和决策归插件。四项资源同包，避免页面／程序／文案分裂换版；沿用已有服务和 relay，不建立通用渲染器、公共领域模型、额外持久表或自动演化平台。独立1.1测试版本改变文案、间距和 compact 阈值，验证这个私有接缝支持真实独立迭代；具体执行结果保留于验收证据。
