# Historical Trace view

These templates and histogram CSS serve only the accepted Trace Inspector 1.0.1
three-service graph and explicitly embedded readers that never enabled managed
workbench resources. The managed path renders `views/trace.html` from its frozen
owning package; missing, rejected or revoked resources never select this copy.

The templates preserve the last accepted Host display, including current shared
control and frozen-page identity mechanisms. Keep this boundary while those
historical graphs/references or explicit direct readers have consumers. Delete it
when those consumers retire; do not add business features to this snapshot.

`trace_legacy_view_v1.go` retains the matching label/title/column/status, node classification and SSR geometry
helpers. The managed candidate allowlist and bindings no longer expose them;
new templates own those choices directly. The unused icon helper has no reader
consumer and is removed rather than retained as compatibility code.

Primary-tab defaults, prior-round predicates and task-action labels are also
historical-only helpers. The current managed facade exposes accepted evidence
capabilities and no Host-selected primary tab list. Backend fact/view validation
continues independently of template grouping and labels.
